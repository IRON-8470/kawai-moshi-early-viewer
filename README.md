# 河合模試 先行閲覧

河合塾の模試結果PDFへのリンクを生成する非公式サイトです。正式公開日前に登録されるPDFリンクを利用して、模試の結果を先行して確認できる場合があります。

## 概要

河合塾の模試について、年度・学年・模試の種類・実施回を選択すると、個人成績表などのPDFへのリンクを生成します。

PDFリンクは正式公開日の前日に登録されるため、公式公開前でも閲覧できる場合があります。

## 使い方

1. サイトを開きます。
2. 年度・学年・模試の種類・実施回を選択します。
3. 「リンクを表示」を押します。
4. 表示されたリンクからPDFを開きます。

**事前に河合塾ポータルへログインしてください。** ログインしていない場合、PDFを閲覧できません。

## 対応模試

以下の6種類に対応しています。

| 学年 | 模試 |
|---|---|
| 高1 | 全統高1模試 |
| 高2 | 全統高2模試 |
| 高2 | 全統記述高2模試 |
| 高2 | 全統共通テスト高2模試 |
| 高3・高卒 | 全統共通テスト模試 |
| 高3・高卒 | 全統記述模試 |

※共通テスト模試では、答案PDFへのリンクは表示されません。

## 注意事項

- 本サイトは河合塾の公式サイトではなく、個人が作成した非公式サイトです。
- PDFリンクが登録されていない場合や、公開前のアクセスが制限されている場合は閲覧できません。
- 本サイトは管理者の利用環境でのみ動作確認を行っています。そのため、ご利用の環境によってはPDFを閲覧できない場合があります。
- PDFの閲覧には河合塾ポータルへのログインが必要です。
